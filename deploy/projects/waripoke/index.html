ワリポケ

レシートを撮影するだけで支払い内容を記録し、最終的に誰が誰にいくら支払えばよいのかを確認できる割り勘アプリです。

Web App / enPiT グループ開発 / 公開停止中 / 2024

課題

旅行や食事で誰かが立て替えると、後から「誰がいくら払ったか」「誰が誰にいくら返すか」を整理するのに手間がかかり、記録漏れや計算ミスも起きがちです。

目的

精算にかかる手間を減らし、友人同士の金銭のやり取りをスムーズにすること。

設計・実装上の工夫

入力をレシート撮影に集約

手入力を減らし、支払いの記録漏れを起こしにくくしました。

結論だけを見せる精算

最終的に誰が誰にいくら支払えばよいのかを確認できるようにしました。

成果

  • 現在は公開を停止しています。デモ動画で動作を確認できます。

使用技術

Python / Django / Tailwind CSS
